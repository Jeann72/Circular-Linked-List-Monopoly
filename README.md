# Circular-Linked-List-Monopoly
## Assignment 
Linked list and monopoly 
Linked Lists are fast to add/remove, but slow to find things.

## add

+Time Complexity: 0(1)
+Already have the tail pointer, so you just snap the new node on(NO WALKING).

## search
+Time Complexity: O(n)
+You don’t have to check a node one by one until you find it.

## remove
Time Complexity: O(n)
You have to walk to find it first, then unlike is instant.

## move
Time Complexity: O(steps)
You take one step at a time(more steps = more time).

## printBoard/print
Time Complexity: O(n)
You visit every node once you display it.
